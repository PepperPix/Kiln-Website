# BuildResult

*(class)*

`Kiln.Models.BuildResult`

Result of a site build operation.

## Properties

### Duration

Gets the elapsed build time.

### Errors

Gets the errors collected during the build.

### OutputDirectory

Gets the path of the output directory.

### RenderedFiles

Gets the number of pages that were rendered.

### SkippedDrafts

Gets the number of draft items that were skipped.

### Success

Gets a value indicating whether the build finished without errors.

### TotalFiles

Gets the number of content items that were read.

### Warnings

Gets the warnings collected during the build.
