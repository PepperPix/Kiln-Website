# SearchOptions

*(class)*

`Engobe.Models.SearchOptions`

Search index settings, read from the `search` section of `site.yaml`.

## Properties

### BinaryPath

Explicit Pagefind binary; an absolute path once loaded from site configuration (relative values resolve against the project directory).

### Enabled

Gets whether a search index is built for the site.

### Extended

Gets whether the extended edition of Pagefind is used.
