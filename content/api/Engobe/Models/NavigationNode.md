# NavigationNode

*(class)*

`Engobe.Models.NavigationNode`

A node of the navigation tree of a collection. Nodes are built from item titles and from the directories (sections) the items reside in.

## Properties

### Children

Gets the child nodes.

### Title

Gets the display title of the node.

### Url

Gets the relative URL of the node, including the base path of the site.

### Weight

Gets the weight used for ordering siblings.
