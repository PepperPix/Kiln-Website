This reference covers the public types of two NuGet packages:

- [`Engobe.Abstractions`](https://www.nuget.org/packages/Engobe.Abstractions): contracts for plugins and hosts, such as `IEngobeBuilder` and `IAssetProcessor`.
- [`Engobe.Core`](https://www.nuget.org/packages/Engobe.Core): the engine, with `ISiteBuilder`, the content models, `SiteConfiguration` and the `AddEngobe()` registration.

It describes version **2.0.0**. The pages are generated from the XML documentation of the published packages.

## Stability

Interfaces, models and `AddEngobe()` are covered by SemVer. Concrete service classes are listed for completeness but may change in any release.

Use the navigation on the left to browse by namespace, or the search field to find a type by name.
